# Emergency Hotline 🚨

A simple and responsive web application that provides quick access to emergency hotline numbers. Designed to be lightweight, user-friendly, and accessible across devices.

## 📦 Deployment
This project is live on **GitHub Pages**.  
To deploy your own version:
1. Fork or clone the repo.
2. Push changes to the `main` branch.
3. Go to **Settings → Pages → Branch → main**.
4. Your site will be published automatically.
